# Webcam to ASCII Converter

A small Python project that converts a live webcam feed into ASCII art in real time using OpenCV and Pillow.

I started this project today as the first step in a much bigger journey. The plan isn't just to build an ASCII webcam, but to experiment with different rendering techniques, computer vision ideas, and graphics effects while learning along the way.

## Built With

- Python
- OpenCV
- Pillow
- NumPy
